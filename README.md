# weather-digest

Утилита командной строки для получения сводки прогноза погоды по одному или нескольким городам. Работает через бесплатные API сервиса Open-Meteo: сначала город преобразуется в координаты (геокодинг), затем запрашивается дневной прогноз (мин./макс. температура и количество осадков). Результаты выводятся в консоль в виде таблицы и сохраняются в виде отчётов на диск.

## Требования к окружению

- Node.js версии 20 и выше (в том числе встроенный `fetch`, поэтому внешние зависимости для HTTP не требуются)
- npm
- Доступ к сети (для запросов к API Open-Meteo)

## Установка

```bash
npm install
```

Для разработки также можно установить зависимости, необходимые для линтинга и тестов, той же командой (devDependencies входят в состав `npm install`).

Если зависимости не установлены, запустите:

```bash
npm ci
```

## Переменные окружения

Все переменные задаются в файле `.env` (пример — в `.env.example`). Файл загружается утилитой автоматически.

| Переменная          | Назначение                                   | Значение по умолчанию                            |
| ------------------- | -------------------------------------------- | ------------------------------------------------ |
| `GEOCODING_API_URL` | URL API геокодинга Open-Meteo                | `https://geocoding-api.open-meteo.com/v1/search` |
| `WEATHER_API_URL`   | URL API прогноза погоды Open-Meteo           | `https://api.open-meteo.com/v1/forecast`         |
| `TIMEOUT`           | Таймаут HTTP-запроса в миллисекундах         | `5000`                                           |
| `REPORTS_DIR`       | Каталог для сохранения отчётов (JSON-файлов) | `reports`                                        |

При запуске через Docker (см. `Dockerfile`) значения `TIMEOUT` и `REPORTS_DIR` задаются автоматически.

## Команды запуска

### Запуск утилиты

```bash
npm start -- [параметры]
```

или напрямую:

```bash
node src/index.js [параметры]
```

Режим разработки с автоматической перезагрузкой при изменениях:

```bash
npm run dev -- [параметры]
```

### Параметры командной строки

| Параметр     | Короткая форма | Тип    | Обязательный | Описание                                                           |
| ------------ | -------------- | ------ | ------------ | ------------------------------------------------------------------ |
| `--city`     | `-c`           | строка | да           | Города через запятую, например `--city "Москва,Казань"`            |
| `--days`     | `-d`           | число  | нет          | Количество дней прогноза от 1 до 7. По умолчанию `3`               |
| `--no-cache` | `-n`           | флаг   | нет          | Игнорировать сохранённые отчёты и всегда запрашивать свежие данные |
| `--help`     | `-h`           | флаг   | нет          | Показать справку                                                   |

### Примеры запуска

```bash
# Прогноз для одного города на 3 дня
npm start -- --city Москва

# Прогноз для нескольких городов на 5 дней
npm start -- --city "Москва,Санкт-Петербург" --days 5

# Запрос свежих данных без использования кэша
npm start -- --city Казань --no-cache

# Сокращённая форма параметров
node src/index.js -c "Москва,Казань" -d 2 -n
```

## Описание обрабатываемых ошибок и кодов завершения

### Коды завершения

| Код | Значение                                                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0` | Успешное завершение — прогноз получен для всех указанных городов                                                                                               |
| `1` | Ошибка: ошибка разбора параметров, неверные значения параметров, либо хотя бы для одного города не удалось получить прогноз; также любая непредвиденная ошибка |

### Описание ошибок

| Условие                                                       | Сообщение в консоли                                                                  |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Не передан обязательный параметр `--city`                     | `Ошибка: параметр --city обязателен`                                                 |
| Передан пустой список городов                                 | `Ошибка: не указан ни один город`                                                    |
| Параметр `--days` не является числом от 1 до 7                | `Ошибка: параметр --days должен быть числом от 1 до 7`                               |
| Город не найден в API геокодинга                              | `Город "<город>" не найден`                                                          |
| Ошибка клиента (HTTP 4xx) при геокодинге                      | `Город "<город>" не найден (ошибка клиента <код>)`                                   |
| Ошибка сервера (HTTP 5xx) при геокодинге                      | `Ошибка сервера геокодинга (<код>)`                                                  |
| Ошибка клиента (HTTP 4xx) при получении прогноза              | `Ошибка клиента при получении прогноза (<код>)`                                      |
| Ошибка сервера (HTTP 5xx) при получении прогноза              | `Ошибка сервера прогноза (<код>)`                                                    |
| Некорректный JSON от сервера                                  | `Некорректный JSON от сервера геокодинга` / `Некорректный JSON от сервера прогноза`  |
| Отсутствуют ежедневные данные в ответе прогноза               | `Некорректные данные прогноза: отсутствуют ежедневные данные`                        |
| Превышен таймаут запроса                                      | `Превышен таймаут запроса (<таймаут> мс)`                                            |
| Отсутствует подключение к сети (`ENOTFOUND` / `ECONNREFUSED`) | `Отсутствует подключение к сети`                                                     |
| Любая непредвиденная ошибка                                   | `Непредвиденная ошибка: <описание>`                                                  |

Ошибки по отдельным городам не прерывают обработку остальных: если один город не удалось обработать, утилита продолжает запрашивать прогнозы для остальных, но в конце завершается с кодом `1`. Ошибка сохранения отчёта не приводит к остановке утилиты — выводятся предупреждение в консоль и код сохранения пропускается.

## Структура проекта

```
geocoding/
├── src/                     # Исходный код
│   ├── index.js            # Точка входа, разбор параметров CLI, вывод результатов
│   ├── api/
│   │   └── weatherApi.js   # HTTP-клиент: геокодинг и получение прогноза, обработка таймаутов и ошибок HTTP
│   ├── services/
│   │   └── weather.js      # Бизнес-логика: связывание геокодинга, прогноза и кэша, параллельная обработка городов
│   ├── format/
│   │   └── output.js       # Форматирование данных прогноза в таблицу для консоли
│   └── storage/
│       └── cache.js        # Сохранение отчётов в JSON и чтение из кэша
├── tests/                   # Автотесты (node:test)
│   ├── client.test.js      # Тесты HTTP-клиента
│   └── services.test.js    # Тесты сервисного слоя
├── docs/
│   └── postman/            # Postman-коллекция для ручной проверки API
├── reports/                 # Каталог сохранённых отчётов (JSON, по умолчанию)
├── Dockerfile               # Образ для запуска в Docker
├── .env.example            # Шаблон переменных окружения
└── package.json            # Описание проекта и скрипты
```
